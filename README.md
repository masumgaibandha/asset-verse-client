# AssetVerse

Live Demo: https://asset-verse-b5fc2.web.app/

Overview:
AssetVerse is a corporate asset management web application designed to track, manage, and monitor company assets efficiently. It provides a centralized dashboard where users can manage assets, assign resources, and maintain records with role-based access.

Asset management systems are used to track and optimize assets throughout their lifecycle, ensuring better control, performance, and decision-making. :contentReference[oaicite:0]{index=0}

Technologies:
- React.js
- JavaScript (ES6)
- Tailwind CSS
- Firebase
- Node.js
- Express.js
- MongoDB

Features:
- Add, update, and delete assets
- Role-based user access (admin / user)
- Asset tracking and management system
- Dashboard with real-time data overview
- Secure authentication system
- Responsive design for all devices

Dependencies:
- react
- react-dom
- firebase
- express
- mongodb
- cors
- dotenv

Run Locally:
git clone https://github.com/masumgaibandha/asset-verse-server.git
cd asset-verse-server
npm install
npm start
